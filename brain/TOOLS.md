# Tools — Pokédex Explorer

**API: PokéAPI** — free, no key, no signup. Documented limits: no hard request cap; fair-use policy = cache responses locally, abusive IPs can be banned. Data is immutable, which is what makes permanent local caching safe.

**Hosting plan:** static files only — GitHub Pages or Vercel static. **TBD by owner** (no repo/deployment created yet).

**Fallback if the API is down:** cached details and type lists keep working from localStorage; uncached pages show the error state with retry. There is no second data source — PokéAPI is the canonical dataset.

**Accounts needed:** none.
