About this project

PokéAPI looks like the friendliest API on the internet — free, no key, everything public. The catch only shows up when you build against it: the list endpoint gives you names and URLs, so a single page of cards needs 24 separate detail calls, and a search box that fires one request per keystroke will happily race itself. I built this Pokédex to practise exactly that discipline — chunked batching instead of request waterfalls, cancelling stale searches, and caching immutable data the way PokéAPI's fair-use policy asks. The "Seen" counter is my favourite small touch: the app remembers which Pokémon you have actually opened, like a real Pokédex.

Part of a series of small, dependency-free apps I built against free public APIs to practise working within real rate limits and payload shapes.
